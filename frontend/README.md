# Flight Delay Predictor - Frontend

Modern, high-performance web client for the Flight Delay & Cancellation Probability Predictor platform.

## Tech Stack
* **React 19**
* **Vite** with HMR and OXC tooling
* **TypeScript**
* **Tailwind CSS v4**
* **Lucide React Icons**
* **Recharts**

## Getting Started
```bash
npm install
npm run dev
```

Runs on [http://localhost:5173](http://localhost:5173). Requests to `/api/*` are reverse-proxied to the FastAPI backend at `http://127.0.0.1:8000`.

## Build
```bash
npm run build
```
